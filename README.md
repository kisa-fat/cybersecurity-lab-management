## Project Description

This is a cybersecurity lab inventory for calculating the risk percentage. 

## Input

1. Total number of systems
2. Number of vulnerable systems

## Processing

Risk Percentage = (Vulnerable Systems ÷ Total Systems) × 100
Risk Percentage = (vulnerableSystems / totalSystems) × 100

## Output

====================================
       CYBERSECURITY RISK REPORT
====================================

Enter the total number of systems: 20
Enter the number of vulnerable systems: 7

------------------------------------
Total Systems: 20
Vulnerable Systems: 7
Risk Percentage: 35.00%
------------------------------------
